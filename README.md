# InputHub plugins

The plugins made by the [InputHub](https://github.com/inputhub/inputhub)
project. Each is a directory of its own here, listed in the
[registry](https://github.com/inputhub/plugin-registry) and installed from
InputHub like any other plugin:

```
inputhub-ctl plugin install media
```

| Plugin | What it brings |
| --- | --- |
| [media](media) | a ring for what is playing: play and pause, next and previous, volume and mute |

They are also examples: a plugin of yours is laid out the same way. How one
is made and listed is in the registry's
[CONTRIBUTING.md](https://github.com/inputhub/plugin-registry/blob/main/CONTRIBUTING.md).
